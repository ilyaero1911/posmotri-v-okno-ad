# Посмотри в окно

Проектная работа по вёрстке интерфейса приложения «Посмотри в окно». На странице можно искать видео по городу и времени суток, просматривать карточки и переключать выбранный ролик.

## Ссылка на репозиторий

https://github.com/ilyaero1911/posmotri-v-okno-ad

## Запуск

Откройте `index.html` в браузере. Для загрузки видео и работы поиска требуется доступ к интернету.

## Файлы проекта

- `index.html` — разметка страницы и шаблоны карточек, прелоадера и ошибки;
- `styles/style.css` — лейаут, оформление и состояния элементов;
- `styles/preloader.css` и `styles/error.css` — стили загрузки и ошибки;
- `scripts/script.js` — загрузка данных, поиск и переключение видео;
- `fonts/` — локальные шрифты.

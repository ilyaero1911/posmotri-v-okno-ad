# Посмотри в окно

Учебный проект по вёрстке интерфейса приложения «Посмотри в окно». Страница показывает видео и карточки городов, позволяет искать ролики по городу и времени суток и переключать выбранное видео.

## Запуск

Откройте `index.html` в браузере. Для загрузки видео и работы поиска требуется доступ к интернету: данные приходят из API, к которому обращается готовый скрипт проекта.

## Состав проекта

- `index.html` — разметка страницы и шаблоны карточек, прелоадера и ошибки;
- `styles/style.css` — лейаут, оформление и состояния интерактивных элементов;
- `styles/preloader.css` и `styles/error.css` — стили состояний загрузки и ошибки;
- `scripts/script.js` — загрузка данных, поиск и переключение видео;
- `fonts/` — локальные шрифты.

Основа проекта — [стартовый репозиторий Яндекс Практикума](https://github.com/yandex-praktikum/posmotri-v-okno-fd). В этой версии дополнены стили интерфейса.
